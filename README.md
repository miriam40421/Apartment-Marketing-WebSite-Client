# 🌐 Real Estate Frontend Client

## 🔍 Overview  
This is a React-based application that serves as the frontend for the Real Estate Marketing Website. Users can browse, filter, and manage properties based on their roles.

---

## ✨ Key Features

- User registration and login  
- Property listing and filtering  
- Admin dashboard for managing properties  
- Role-based interface (Admin / Client)

---

## 🛠 Technologies

- React  
- Axios  
- React Router  
- Tailwind or Bootstrap (optional)

---

## ⚙️ Installation and Running

1. Navigate to the client folder:
   ```bash
   cd client
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
4. Open your browser at:  
   [http://localhost:3000](http://localhost:3000)

---

## 📁 Folder Structure

```
/src
  /components
  /services
  /pages
  App.js
```

---

## 🔐 Security Notes

- JWT token is stored in LocalStorage  
- Content is conditionally rendered based on user role  
- API calls are secured using Axios
